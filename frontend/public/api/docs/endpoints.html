Brubru EU Data API · v2 · 482 endpoints across 34 EU institution folders

All endpoints

The complete Brubru EU Data API surface, organised one folder per EU institution or body. Every endpoint below is on the v2 API and authenticated with a single API key. This list is hand-grouped for browsing; the live API reference renders the same endpoints directly from the OpenAPI spec, so it is always exactly in sync with what is deployed.

One key, one envelope. Every call takes the same Authorization: Bearer brubru_live_... header and every list endpoint returns the same paginated response envelope. Detail endpoints (paths ending in an id, CELEX, reference or slug) return a single object. Base URL: https://brubru.beresol.eu/api/v2.
