GET /api/v1/laws/{celex}/text Auth

Full text of a specific EU law. Tries local Formex XML cache first; falls back to EUR-Lex Cellar (publications.europa.eu/resource/celex/{celex}) if not cached.

Path parameters

celexstringCELEX identifier.

Query parameters

formatplain | xmlDefault plain — whitespace-normalised text. xml returns raw Formex.
 
curl -H "Authorization: Bearer $KEY" \
  "https://brubru-production.up.railway.app/api/v1/laws/32016R0679/text?format=plain"
{
  "celex": "32016R0679",
  "title": "Regulation (EU) 2016/679 ... General Data Protection Regulation",
  "doc_type": "Regulation",
  "adopted_on": "2016-04-27",
  "format": "plain",
  "content": "REGULATION (EU) 2016/679 OF THE EUROPEAN PARLIAMENT AND OF THE COUNCIL ...",
  "content_length": 351521,
  "eurlex_url": "https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32016R0679"
}

Content can be hundreds of KB for regulations. Use format=plain for LLM input; format=xml if you need structure preserved.

Procedures

GET /api/v1/procedures Auth

EU legislative procedures in flight. 1,464 files tracked from Commission proposal to adoption.

Query parameters

NameTypeDescription
qstringSubstring match on title.
referencestringOEIL reference e.g. 2025/0726(COD).
committeestringLead committee code (LIBE, ENVI, ...).
rapporteur_mep_idstringFilter by rapporteur.
statusstringCarriage status (announced, tabled, adopted, ...).
updated_from / updated_to / updated_enddatetimeLast-updated bounds. updated_end is alias of updated_to.
limit / pageintDefault 50 / 1.
 
curl -H "Authorization: Bearer $KEY" \
  "https://brubru-production.up.railway.app/api/v1/procedures?committee=LIBE&limit=3"

Cross-references shipped with every row

  • url — canonical OEIL page on oeil.secure.europarl.europa.eu.
  • legal_text_url — EUR-Lex link to the adopted text (when available).
  • law_tracker_url — the EU's aggregated procedure tracker on law-tracker.europa.eu. Mapping: OEIL 2025/0420(COD) → https://law-tracker.europa.eu/procedure/2025_420?lang=en. Combines OEIL + EUR-Lex + Commission events on a single page. Returns null when the reference isn't an OEIL procedure (e.g. COM-numbered drafts).

Legal-text intelligence

These endpoints expose Brubru's derived analyses of EU legal texts. The two POST endpoints are READ-ONLY idempotent — they're POST only because the request body may contain long user text.

GET /api/v1/legal-text/{celex}/recital-article-map Auth

Top-3 recitals motivating each article of a law. TF-IDF cosine similarity. Cached per CELEX.

Query parameters

force_recomputeboolBypass cache, rebuild the map. Default false.
 
curl -H "Authorization: Bearer $KEY" \
  https://brubru-production.up.railway.app/api/v1/legal-text/32016R0679/recital-article-map
{
  "celex": "32016R0679",
  "map": {
    "Article 3": [
      {"recital_number": "27", "score": 0.41, "snippet": "..."},
      {"recital_number": "14", "score": 0.35, "snippet": "..."},
      {"recital_number": "23", "score": 0.30, "snippet": "..."}
    ],
    "Article 6": [...],
    ...
  }
