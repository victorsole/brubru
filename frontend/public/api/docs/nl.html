Brubru EU Data API · v2 · 935 endpoints in 88 mappen van EU-instellingen

De EU, gestructureerd.

Brubru is een verticale EU-dataleverancier. Onze REST-API geeft ontwikkelaars, RegTech-platforms, public-affairsteams en AI-agents programmatische toegang tot 8.710 vastgestelde EU-wetten (28.513 PB-publicaties), 2.080 gevolgde wetgevingsdossiers, 16.521 EU-ambtenaren, alle Europarlementariërs, 58.399 EP-amendementen, de registers van Parlement / Raad / Europese Raad / Eurogroep / Commissie, de Europese Centrale Bank en de financiële instellingen van de EU, de gedecentraliseerde EU-agentschappen (geneesmiddelen, voedselveiligheid, milieu, chemische stoffen, drugs, grondrechten en meer), EU-financiering en aanbestedingen, de 19 aanvraagmodellen voor Europese fondsen van Brubru's Tender Docs, open data inclusief 12 samengestelde Eurostat-reeksen over sport en fitness-relevante gezondheid live opgehaald, en Brubru's eigen EU-intelligentie. Dezelfde data die wij intern gebruiken, roept u aan. Brubru is de eerste klant van zijn eigen API.

Eén oppervlak, één sleutel. De API is ingedeeld zoals de EU zelf: één map per instelling of orgaan, 88 mappen in totaal, 935 endpoints. Blader hieronder door de mappen of open de volledige, altijd actuele API-referentie →: elk uitgerold endpoint, live gegenereerd uit de OpenAPI-specificatie.

Nieuw met API's? Een API is een manier voor uw software om via internet met de software van Brubru te praten. U stuurt een HTTP-verzoek (zoals een browser doet) en wij sturen JSON terug (gestructureerde data). De rest van deze documentatie legt uit hoe.

Authenticatie in een oogopslag

Elke call naar /api/v2/* vereist een API-sleutel, verstuurd als Bearer-token of als X-API-Key-header:

curl -H "Authorization: Bearer brubru_live_..." \
  "https://brubru.beresol.eu/api/v2/legislative/eur-lex/laws?q=artificial+intelligence&limit=5"

Volledige details op Authenticatie.

De response-envelop in een oogopslag

Elk gepagineerd endpoint geeft dezelfde vorm terug. Programmeer één keer tegen deze envelop en wissel van dataset door het pad te wijzigen:

{
  "total": 139,
  "returned": 20,
  "pages": 7,
  "page": 1,
  "limit": 50,
  "has_more": true,
  "next_page": 2,
  "remaining_pages": 6,
  "coverage_complete": true,
  "published_from": "2026-01-01",
  "published_to": "2026-01-31",
  "published_end": "2026-01-31",
  "detail_level": "Full",
  "data": [ ... ]
}

Herkomst en rate-limit-informatie staan in de response-headers, niet in de body:

X-Powered-By: Brubru
X-Source: brubru.beresol.eu
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 58
X-RateLimit-Tier: free

Snelstart: uw eerste call

1. Vraag een API-sleutel aan. Mail hello@beresol.eu zodra u het Professional-abonnement hebt. Sleutels zien eruit als brubru_live_ gevolgd door 48 hexadecimale tekens.

2. Controleer of de service draait. De health-check is openbaar: geen sleutel nodig:

curl "https://brubru.beresol.eu/health"

Antwoord:

{
  "status": "ok",
  "service": "brubru-data-provider",
  "time": "2026-04-20T15:00:00Z"
}

3. Probeer een echte zoekopdracht.

curl -H "Authorization: Bearer $BRUBRU_API_KEY" \
  "https://brubru.beresol.eu/api/v2/legislative/eur-lex/laws?q=artificial+intelligence&limit=3"

U krijgt een gepagineerde lijst van EU-wetten die overeenkomen met "artificial intelligence", met CELEX-identificatoren, titels, datums en EUR-Lex-URL's. Vanaf daar volgt elk endpoint hetzelfde envelop-patroon: wijzig alleen het pad.

Beperkingen (wat we niet dekken)

  • Niet-EU-wetgeving. We volgen nationale staatsbladen niet rechtstreeks. Hebt u het Spaanse BOE samen met de EU nodig, combineer ons dan met GovClipping of vergelijkbaar.
  • Realtime push. Nog geen webhooks of SSE. Het integratiepatroon is polling volgens onze frequentie. Webhooks op de roadmap voor september 2026.
  • Talen. API-antwoorden zijn vandaag in het Engels. Sommige wetteksten zijn beschikbaar in alle 24 EU-talen via Cellar, maar de gestructureerde antwoorden zijn alleen in het Engels. Meertalige endpoints in september 2026.
  • Bulkexports. Nog geen nachtelijke CSV/Parquet-dumps. Roadmap september 2026. Doorloop voorlopig de gepagineerde lijsten.
  • Nationale parlementen. We nemen geen data op van nationale parlementen. Alleen het EP.

Clientbibliotheken

Twee officiële Python-bibliotheken zijn in ontwikkeling om de API en de EuroVoc-classifier op één import afstand te brengen. De REST-API is vandaag al live: bouw voorlopig tegen de endpoints. Gebouwd en getest, installeerbaar vanaf de broncode (publicatie op PyPI volgt).

pip install ./sdk/brubru
pip install "./sdk/eurovoc[local]"   # [local] adds the classifier model

brubru: een lichte Python-SDK boven op de v2-API. Getypeerde objecten over het 5-datapuntcontract, automatische paginering en eerlijke fouten. De eigen client van de API.

import brubru

bru = brubru.Client(api_key="brubru_live_...")
items = bru.extract("https://cinea.ec.europa.eu/news_en", classify=True)
posts = bru.social.posts(entity_type="commissioner", platform="x")

eurovoc: een op zichzelf staande, open-source EuroVoc-classifier. Het labelt elke tekst in de officiële onderwerpsruimte van de EU (7.029 descriptoren, 127 microthesauri, 21 domeinen), meertalig inclusief Catalaans. Een moderne opvolger van het PyEuroVoc-pakket uit 2021.

import eurovoc

eurovoc.classify("Markets in crypto-assets regulation")
# -> [{"descriptor": "financial instrument", "mt": "2426", "domain": "24", "score": 0.88}, ...]
