Brubru EU Data API · v1 + v2 · 200+ eindpunten verspreid over 33 EU-instellingsdomeinen

De EU, gestructureerd.

Brubru is een verticale EU-dataprovider. Onze REST API geeft ontwikkelaars, RegTech-platforms, public-affairs-teams en AI-agenten programmatische toegang tot 8.710 aangenomen EU-wetten (28.513 OJ-publicaties), 1.717 lopende wetgevingsprocedures, 14.873 EU-ambtenaren in elke instelling, 56.051 amendementen, 1.026 EP-verslagen, 386 aanbestedingen (TED), 210 onderzoekspublicaties (EPRS, STOA, JRC, ART, ECA), 528 Commissie-registerdocumenten, 227 samengestelde beleidshandleidingen, live commissaris-agenda's, EP-webstreams, de juridische-tekstintelligentie-laag die Brubru's eigen chatbot en Amendator aandrijft, en een nieuwe gespecialiseerde EC-databasesmap die 10 institutionele oppervlakken bedekt die geen andere leverancier blootstelt via één API-sleutel: 6.002 GBVB-gesanctioneerde personen/entiteiten, 17.247 Transparantieregister-lobbyistenorganisaties, 83.807 comitologie-documenten, 5.917 geografische aanduidingen, 900 internationale overeenkomsten, 675 handelsverdedigingsmaatregelen, live DG COMP-mededingingszaken (~250k upstream), 3.543 JRC-gegevenssets, 1.451 DG REGIO-cohesigegevenssets, en live Combined Nomenclature-opzoeken. De gegevens die we intern gebruiken, zijn wat jij aanroept. Brubru is de eerste klant van zijn eigen API.

Nieuw: API v2 reorganiseert alles rond de EU-instellingen, één map per orgaan, en voegt de institutionele databases toe die geen andere leverancier blootstelt — de Parlementsregisters (MEP-verklaringen, geaccrediteerde assistenten, commissie-ondersteunende analyses), de Raadssanctieregelingen, de EU-agentschapsdatabases (geneesmiddelen, voedselveiligheidsgegevenssets, milieu-indicatoren, de REACH SVHC-kandidatenlijst, de medicijnenbibliotheek, grondrechten-jurisprudentie en Charterpedia), en meer. Zie de volledige, altijd-actuele API-referentie → — elk uitgerolde eindpunt, weergegeven live uit de OpenAPI-specificatie.

Nieuw voor API's? Een API is een manier waarop uw software met Brubru's software via internet kan communiceren. U stuurt een HTTP-verzoek (zoals een webbrowser doet), wij sturen JSON terug (gestructureerde gegevens). De rest van deze documenten legt uit hoe het werkt.

Wat je krijgt

Wetgeving (8 mappen)

Wetten
8.710 aangenomen EU-wetten (28.513 OJ-publicaties) doorzoekbaar op CELEX, beleidsgebied, datum of volledige tekst. Haal volledige XML of gewone-tekst-body op.
Procedures
1.464 wetgevingsbestanden gevolgd van Commissievoorstel tot aanneming. OEIL-referenties, commissies, rapporteurs, status.
Juridische-tekstintelligentie
Overwegings-artikel-mapping, gedefinieerde-term-extractie, CELEX-referentie-resolver, wetaliasoplosser (680+ acroniemen).
Gedelegeerde besluiten

Uitvoeringsbesluiten

TRIS-mededelingen

Verslagen

Adviezen
Adviezen van betrokken commissies (rapporteur voor advies, RR-referenties).
Parlementaire vragen

Authenticatie in een oogopslag

Elke /api/v1/*-oproep vereist een API-sleutel die wordt doorgegeven als Bearer-token of X-API-Key-header:

curl -H "Authorization: Bearer brubru_live_..." \
  "https://brubru-production.up.railway.app/api/v1/laws?q=artificial+intelligence&limit=5"

Volledige details op Authenticatie.

Antwoord-envelop in een oogopslag

Elk gepagineerd eindpunt retourneert dezelfde vorm. Codeer eenmaal tegen deze envelop en wissel gegevenssets uit door het pad te veranderen:

{
  "total": 139,
  "returned": 20,
  "pages": 7,
  "page": 1,
  "limit": 50,
  "has_more": true,
  "next_page": 2,
  "remaining_pages": 6,
  "coverage_complete": true,
  "published_from": "2026-01-01",
  "published_to": "2026-01-31",
  "published_end": "2026-01-31",
  "detail_level": "Full",
  "data": [ ... ]
}

Herkomst- en snelheidsbeperking-informatie bevinden zich in antwoordheaders, niet in de body:

X-Powered-By: Brubru
X-Source: brubru.beresol.eu
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 58
X-RateLimit-Tier: free

Volledige details op Antwoord-envelop.

Snelstart: je eerste oproep

1. Haal een API-sleutel. Email hello@beresol.eu nadat je bent aangemeld voor het Professional-abonnement. Sleutels zien eruit als brubru_live_ gevolgd door 48 hexadecimale tekens.

2. Maak een oproep.

curl -H "Authorization: Bearer $BRUBRU_API_KEY" \
  "https://brubru-production.up.railway.app/api/v1/ping"

Antwoord (deze is openbaar, geen auth vereist):

{
  "status": "ok",
  "service": "brubru-data-provider",
  "version": "v1",
  "time": "2026-04-20T15:00:00Z"
}

3. Probeer een echte zoekopdracht.

curl -H "Authorization: Bearer $BRUBRU_API_KEY" \
  "https://brubru-production.up.railway.app/api/v1/laws?q=artificial+intelligence&limit=3"

Je krijgt een gepagineerde lijst van EU-wetten die overeenkomen met "artificial intelligence", met CELEX-identificators, titels, datums en EUR-Lex-URL's. Vanaf daar volgen alle andere eindpunten dezelfde envelop-patroon.

Beperkingen (wat we niet behandelen)

  • Niet-EU-wetgeving. We volgen nationale gazetten niet direct. Als je Spaanse BOE + EU samen nodig hebt, combineer ons met GovClipping of soortgelijk.
  • Real-time push. Nog geen webhooks of SSE. Polling op onze vernieuwingscadence is het integratiepatroon. Webhooks op de septemberroutekaart 2026.
  • Talen. API-antwoorden zijn vandaag Engels. Sommige wetteksten zijn beschikbaar in alle 24 EU-talen via de Cellar-fallback, maar de gestructureerde antwoorden zijn alleen in het Engels. Meertalige eindpunten in september 2026.
  • Bulkexport. Nog geen nachtelijke CSV/Parquet-dumps. Routekaart september 2026. Herhaal voorlopig gepagineerde lijsten.
  • Nationale parlementen. We nemen niet in van nationale parlementen. Alleen EP.
