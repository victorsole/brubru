Use cases by role

What you'd actually call, in what order, to do your job. Each section maps a professional role to a concrete call sequence with examples.

Public-affairs consultant

You run a small consultancy or work in a larger one. Clients pay for briefings and advice on EU regulation affecting their sector. Your morning routine: scan what moved in the last 24 hours across the files your clients care about, write the memo before the client calls.

Morning monitoring

# Recently published EU acts in the digital policy area
curl -H "Authorization: Bearer $KEY" \
  "https://brubru.beresol.eu/api/v2/legislative/eur-lex/recent?policy_area=digital&limit=50"

Then per hit, pull context:

# Is there a procedure behind this announcement?
curl -H "Authorization: Bearer $KEY" \
  "https://brubru.beresol.eu/api/v2/legislative/oeil/procedures?q=<topic>&limit=5"

# What does EPRS say about it?
curl -H "Authorization: Bearer $KEY" \
  "https://brubru.beresol.eu/api/v2/parliament/eprs?q=<topic>&limit=5"

Briefing prep

# Procedure state, rapporteur, committee
curl -H "Authorization: Bearer $KEY" \
  "https://brubru.beresol.eu/api/v2/legislative/oeil/procedures/2022%2F0277%28COD%29"

# EPRS briefings on it
curl -H "Authorization: Bearer $KEY" \
  "https://brubru.beresol.eu/api/v2/parliament/eprs?procedure_ref=2022/0277(COD)"

# Latest committee activity
curl -H "Authorization: Bearer $KEY" \
  "https://brubru.beresol.eu/api/v2/parliament/committees/LIBE/minutes?limit=5"

# Procedure timeline with all stages
curl -H "Authorization: Bearer $KEY" \
  "https://brubru.beresol.eu/api/v2/legislative/oeil/procedures/2022%2F0277%28COD%29"

Draft support

# Extract the law's defined terms to paste into your memo
curl -H "Authorization: Bearer $KEY" \
  "https://brubru.beresol.eu/api/v2/legislative/eur-lex/laws/32024R1689/defined-terms"

National-to-EU linking (the killer use case)

You have text from a Spanish BOE decree. Find the parent EU regulation automatically:

curl -X POST -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"text": "Real Decreto 123/2026, por el que se transpone la Directiva (UE) 2024/1234 sobre ciberseguridad"}' \
  https://brubru.beresol.eu/api/v2/legislative/eur-lex/resolve-references

Response tells you which CELEX the Spanish decree transposes. Then fetch the EU procedure:

curl -H "Authorization: Bearer $KEY" \
  "https://brubru.beresol.eu/api/v2/legislative/oeil/procedures?q=cybersecurity&limit=3"

Academic researcher

You're building a dataset for a paper on EU legislative productivity, or teaching an EU politics class.

Build a dataset

# All regulations in the Digital policy area adopted since 2020
PAGE=1
while : ; do
  curl -s -H "Authorization: Bearer $KEY" \
    "https://brubru.beresol.eu/api/v2/legislative/eur-lex/laws?policy_area=Digital&doc_type=Regulation&published_from=2020-01-01&limit=100&page=$PAGE" \
    >> dataset.jsonl
  HAS_MORE=$(tail -1 dataset.jsonl | jq .has_more)
  [ "$HAS_MORE" = "true" ] || break
  PAGE=$((PAGE+1))
done

Trace a law's legislative history

curl -H "Authorization: Bearer $KEY" \
  "https://brubru.beresol.eu/api/v2/legislative/oeil/procedures?q=GDPR&limit=1"

# Then committee work
curl -H "Authorization: Bearer $KEY" \
  "https://brubru.beresol.eu/api/v2/parliament/committees/LIBE/work-items?q=data+protection"

RegTech platform augmentation

You have domain-specific sector expertise (pharma, fintech, energy). You use Brubru as the EU regulatory layer: we tell you what exists, what's in flight, and what's transposing; you overlay your sector's compliance guidance.

Consultancy firm internal

Daily internal newsletter pulls /api/v2/legislative/eur-lex/recent with the firm's top-20 policy areas as filters; routes hits to the responsible partner. Procedure timeline data from /api/v2/legislative/oeil/procedures/{reference} feeds quarterly forecasting decks.

Academic / research

Build longitudinal datasets via paginated /api/v2/legislative/eur-lex/laws and /api/v2/legislative/oeil/procedures. Combine with /api/v2/parliament/eprs for expert commentary. Our CSV bulk export (roadmap September 2026) will make this faster; for now iterate pages.
