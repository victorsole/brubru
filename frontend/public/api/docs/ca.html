Brubru EU Data API · v2 · 935 endpoints en 88 carpetes d'institucions de la UE

La UE, estructurada.

Brubru és un proveïdor vertical de dades de la UE. La nostra API REST dona a desenvolupadors, plataformes RegTech, equips d'afers públics i agents d'IA accés programàtic a 8.710 lleis de la UE adoptades (28.513 publicacions del DO), 2.080 expedients legislatius en seguiment, 16.521 funcionaris de la UE, tots els eurodiputats, 58.399 esmenes del PE, els registres del Parlament / Consell / Consell Europeu / Eurogrup / Comissió, el Banc Central Europeu i les institucions financeres de la UE, les agències descentralitzades de la UE (medicaments, seguretat alimentària, medi ambient, substàncies químiques, drogues, drets fonamentals i més), finançament i licitacions de la UE, les 19 plantilles d'aplicació a fons europeus de Tender Docs de Brubru, dades obertes que inclouen 12 sèries curades d'Eurostat de salut i esport per al fitness servides en directe i la intel·ligència pròpia de Brubru sobre la UE. Les mateixes dades que fem servir internament són les que crideu. Brubru és el primer client de la seva pròpia API.

Una superfície, una clau. L'API està organitzada com la mateixa UE: una carpeta per institució o organisme, 88 carpetes en total, 935 endpoints. Exploreu les carpetes a continuació, o obriu la referència completa i sempre actualitzada de l'API →: cada endpoint desplegat, generat en directe des de l'especificació OpenAPI.

Nou en les API? Una API és una manera que el vostre programari parli amb el programari de Brubru per internet. Envieu una petició HTTP (com fa un navegador) i us retornem JSON (dades estructurades). La resta d'aquesta documentació explica com.

Què obteniu

Cada carpeta correspon a una institució o organisme de la UE. Les xifres són exactes i s'actualitzen a mesura que creix l'API.

L'autenticació d'un cop d'ull

Cada crida a /api/v2/* requereix una clau d'API enviada com a token Bearer o com a capçalera X-API-Key:

curl -H "Authorization: Bearer brubru_live_..." \
  "https://brubru.beresol.eu/api/v2/legislative/eur-lex/laws?q=artificial+intelligence&limit=5"

Inici ràpid: la vostra primera crida

1. Aconseguiu una clau d'API. Escriviu a hello@beresol.eu quan tingueu la subscripció Professional. Les claus tenen la forma brubru_live_ seguit de 48 caràcters hexadecimals.

2. Comproveu que el servei funciona. La comprovació d'estat és pública: no cal clau:

curl "https://brubru.beresol.eu/health"

Resposta:

{
  "status": "ok",
  "service": "brubru-data-provider",
  "time": "2026-04-20T15:00:00Z"
}

3. Proveu una cerca real.

curl -H "Authorization: Bearer $BRUBRU_API_KEY" \
  "https://brubru.beresol.eu/api/v2/legislative/eur-lex/laws?q=artificial+intelligence&limit=3"

Obteniu una llista paginada de lleis de la UE que coincideixen amb "artificial intelligence", amb identificadors CELEX, títols, dates i URL d'EUR-Lex. A partir d'aquí, cada endpoint segueix el mateix patró de sobre: només cal canviar la ruta.

Limitacions (què no cobrim)

  • Legislació no comunitària. No seguim els butlletins nacionals directament. Si necessiteu el BOE espanyol juntament amb la UE, combineu-nos amb GovClipping o similar.
  • Notificació en temps real. Encara no hi ha webhooks ni SSE. El patró d'integració és el sondeig segons la nostra freqüència. Webhooks al full de ruta de setembre de 2026.
  • Llengües. Les respostes de l'API són avui en anglès. Alguns textos legals estan disponibles en les 24 llengües de la UE via Cellar, però les respostes estructurades són només en anglès. Endpoints multilingües al setembre de 2026.
  • Exportacions massives. Encara no hi ha bolcats nocturns CSV/Parquet. Full de ruta setembre de 2026. De moment, recorreu les llistes paginades.
  • Parlaments nacionals. No ingerim dels parlaments nacionals. Només el PE.

Biblioteques client

Dues biblioteques oficials de Python estan en desenvolupament per deixar l'API i el seu classificador EuroVoc a només un import de distància. L'API REST ja és activa: integra't amb els endpoints mentrestant. Construïdes i provades, instal·lables des del codi font (publicació a PyPI pendent).

pip install ./sdk/brubru
pip install "./sdk/eurovoc[local]"   # [local] adds the classifier model

brubru: un SDK lleuger de Python sobre l'API v2. Objectes tipats sobre el contracte de 5 dades, paginació automàtica i errors honestos. El client propi de l'API.

import brubru

bru = brubru.Client(api_key="brubru_live_...")
items = bru.extract("https://cinea.ec.europa.eu/news_en", classify=True)
posts = bru.social.posts(entity_type="commissioner", platform="x")

eurovoc: un classificador EuroVoc independent i de codi obert. Etiqueta qualsevol text en l'espai temàtic oficial de la UE (7.029 descriptors, 127 microtesaurus, 21 dominis), multilingüe inclòs el català. Un successor modern del paquet PyEuroVoc de 2021.

import eurovoc

eurovoc.classify("Markets in crypto-assets regulation")
# -> [{"descriptor": "financial instrument", "mt": "2426", "domain": "24", "score": 0.88}, ...]
