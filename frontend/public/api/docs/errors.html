Errors

Error responses

Every non-2xx response on /api/v2/* uses the same canonical envelope. Machine-readable reason_codes let you switch on error types without parsing free-text messages.

Error envelope

{
  "error": "Unauthorized: Missing API key",
  "reason_code": "auth_missing_key",
  "request_id": "f9e3a1b2-4c5d-6e7f-8a9b-0c1d2e3f4a5b"
}
FieldMeaning
errorHuman-readable message. Never parse this; use reason_code.
reason_codeStable machine-readable code. Safe to switch on.
request_idUUID4. Echoed in the X-Request-Id response header. Include this when emailing support.

HTTP status codes

CodeMeaning
200Success.
401Missing, malformed, or revoked API key.

403Key valid but this route is outside its scopes or its named routes, or the account is inactive.
404Resource not found.

429Rate limit exceeded (60/min per key). See Retry-After header.
500Unhandled server error. Include request_id when reporting.
502Upstream EU portal temporarily unavailable.

X-Request-Id header

Every response, successful or not, carries an X-Request-Id header. This equals the request_id in error bodies. When you report an issue, include it: we can find the exact request in our logs.

You can also supply your own X-Request-Id on the request; we honour it as long as it's ≤ 64 characters. Helpful for distributed tracing.

Recovery patterns

Rate limit (429)

Retry-After: 7
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 0

Back off for Retry-After seconds. In Python:

if r.status_code == 429:
    time.sleep(int(r.headers.get("Retry-After", 60)))
    continue  # retry

Upstream error (502)

Something outside Brubru is broken (Have Your Say portal is down, Commission calendar is slow). Retry with exponential backoff up to 3 times. If it persists > 30 minutes, email us.

Conflicting params (422 conflicting_params)

You sent published_to AND published_end with different values. Pick one (prefer published_to) and retry.

Computation unavailable (503)

Specific to /legal-text/{celex}/recital-article-map. The TF-IDF parser can fail on edge-case XML. Fall back to /legal-text/{celex}/defined-terms which exercises a different parser. Email us the CELEX so we can debug.
