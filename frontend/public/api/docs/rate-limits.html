Rate limits

Rate limits

Three per-key tiers: free 60, pro 300, enterprise 6000 requests / minute. Sliding-window enforcement. Your tier is on the X-RateLimit-Tier header of every response and on /whoami.

Tier table

TierPer-minute limitMonthly quotaWho gets it
free60 req/minUnlimitedTrial keys + Professional default
pro300 req/minUnlimitedProduction integrations on request — email hello@beresol.eu
enterprise6,000 req/minUnlimitedPartner integrations (e.g. GovClipping). Custom contract.

The limit uses a sliding window over the last 60 seconds, not fixed calendar minutes. Bursting is allowed as long as you stay under your tier's ceiling in any rolling 60-second window.

Response headers

Every response carries:

  • X-RateLimit-Limit — your tier's per-minute ceiling (60 / 300 / 6000).
  • X-RateLimit-Remaining — calls left in the current 60-second window.
  • X-RateLimit-Tier — free, pro, or enterprise.

On 429 responses, additionally:

  • Retry-After — seconds to wait before retrying.

When you hit the limit

You get a 429 rate_limited response. The right behaviour is:

  1. Read Retry-After.
  2. Sleep that many seconds.
  3. Retry the same request.
import time, httpx

def call_with_backoff(url, headers):
    for attempt in range(5):
        r = httpx.get(url, headers=headers)
        if r.status_code != 429:
            return r
        wait = int(r.headers.get("Retry-After", 60))
        time.sleep(wait)
    r.raise_for_status()

Good citizenship

  • Cache aggressively. Our data refreshes daily for most endpoints. Don't poll faster than you need.
  • Batch filters. Ask for limit=100 once instead of 10 calls with limit=10.
  • Use If-None-Match when we expose ETags (June 2026 roadmap).
  • Monitor Newman runs. In CI, set newman run --delay-request 1000 to pace calls.

Need higher limits?

Email hello@beresol.eu with your use case. pro upgrades are usually approved within 24h for production integrations. enterprise is a custom contract for partner integrations — bundling resale rights, SLA, and the 6,000 req/min ceiling.
