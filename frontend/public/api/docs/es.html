Brubru EU Data API · v2 · 935 endpoints en 88 carpetas de instituciones de la UE

La UE, estructurada.

Brubru es un proveedor vertical de datos de la UE. Nuestra API REST da a desarrolladores, plataformas RegTech, equipos de asuntos públicos y agentes de IA acceso programático a 8.710 leyes de la UE adoptadas (28.513 publicaciones del DO), 2.080 expedientes legislativos en seguimiento, 16.521 funcionarios de la UE, todos los eurodiputados, 58.399 enmiendas del PE, los registros del Parlamento / Consejo / Consejo Europeo / Eurogrupo / Comisión, el Banco Central Europeo y las instituciones financieras de la UE, las agencias descentralizadas de la UE (medicamentos, seguridad alimentaria, medio ambiente, sustancias químicas, drogas, derechos fundamentales y más), financiación y licitaciones de la UE, las 19 plantillas de aplicación a fondos europeos que utiliza Tender Docs de Brubru, datos abiertos que incluyen 12 series curadas de Eurostat de deporte y salud relevante para el fitness servidas en directo y la propia inteligencia de Brubru sobre la UE. Los mismos datos que usamos internamente son los que usted consulta. Brubru es el primer cliente de su propia API.

Una superficie, una clave. La API está organizada como la propia UE: una carpeta por institución u organismo, 88 carpetas en total, 935 endpoints. Explore las carpetas a continuación o abra la referencia completa y siempre actualizada de la API →: cada endpoint desplegado, generado en vivo desde la especificación OpenAPI.

¿Nuevo en las API? Una API es una forma de que su software hable con el software de Brubru por internet. Usted envía una petición HTTP (como hace un navegador) y nosotros devolvemos JSON (datos estructurados). El resto de esta documentación explica cómo.

Qué obtiene

Cada carpeta corresponde a una institución u organismo de la UE. Las cifras son exactas y se actualizan a medida que crece la API.

Legislación (1 carpeta)

Legislación y procedimientos
8.710 leyes adoptadas (28.513 publicaciones del DO) y 2.080 expedientes legislativos en seguimiento, más actos delegados y de ejecución, texto completo + XML, mapas de considerandos a artículos, términos definidos, EuroVoc, el Tren Legislativo y los resolvedores de citas y alias.

Parlamento Europeo (1 carpeta)

Parlamento Europeo
Eurodiputados, trabajo en comisión, enmiendas, informes, opiniones, resoluciones, textos aprobados y presentados, votaciones nominales, preguntas parlamentarias, documentos de eMeeting, retransmisiones web + transcripciones de IA, investigación EPRS y declaraciones y asistentes de los eurodiputados.

Fuentes de datos y frecuencia de actualización

Autenticación de un vistazo

Cada llamada a /api/v2/* requiere una clave de API enviada como token Bearer o como cabecera X-API-Key:

curl -H "Authorization: Bearer brubru_live_..." \
  "https://brubru.beresol.eu/api/v2/legislative/eur-lex/laws?q=artificial+intelligence&limit=5"

El sobre de respuesta de un vistazo

Cada endpoint paginado devuelve la misma forma. Programe una vez contra este sobre y cambie de conjunto de datos cambiando la ruta:

{

  "returned": 20,
  "pages": 7,
  "page": 1,
  "limit": 50,
  "has_more": true,
  "next_page": 2,

Inicio rápido: su primera llamada

1. Consiga una clave de API. Escriba a hello@beresol.eu cuando tenga la suscripción Professional. Las claves tienen la forma brubru_live_ seguido de 48 caracteres hexadecimales.

2. Compruebe que el servicio funciona. El chequeo de salud es público: no requiere clave:

curl "https://brubru.beresol.eu/health"

Respuesta:

{
  "status": "ok",
  "service": "brubru-data-provider",
  "time": "2026-04-20T15:00:00Z"
}

3. Pruebe una búsqueda real.

curl -H "Authorization: Bearer $BRUBRU_API_KEY" \
  "https://brubru.beresol.eu/api/v2/legislative/eur-lex/laws?q=artificial+intelligence&limit=3"

Obtiene una lista paginada de leyes de la UE que coinciden con "artificial intelligence", con identificadores CELEX, títulos, fechas y URL de EUR-Lex. A partir de ahí, cada endpoint sigue el mismo patrón de sobre: solo cambie la ruta.

Limitaciones (lo que no cubrimos)

  • Legislación no comunitaria. No seguimos los boletínes nacionales directamente. Si necesita el BOE español junto con la UE, combínenos con GovClipping o similar.
  • Notificación en tiempo real. Aún no hay webhooks ni SSE. El patrón de integración es el sondeo según nuestra frecuencia. Webhooks en la hoja de ruta de septiembre de 2026.
  • Idiomas. Las respuestas de la API están hoy en inglés. Algunos textos legales están disponibles en las 24 lenguas de la UE vía Cellar, pero las respuestas estructuradas son solo en inglés. Endpoints multilingües en septiembre de 2026.
  • Exportaciones masivas. Aún no hay volcados nocturnos CSV/Parquet. Hoja de ruta de septiembre de 2026. Por ahora, recorra las listas paginadas.
  • Parlamentos nacionales. No ingerimos de los parlamentos nacionales. Solo el PE.

Bibliotecas cliente

Dos bibliotecas oficiales de Python, ya en PyPI y de código abierto (MIT), en github.com/Beresol-BV/brubru-EU-scraper-library. Instálalas con pip:

pip install brubru
pip install "brubru-eurovoc[local]"   # [local] adds the classifier model

brubru: un SDK ligero de Python sobre la API v2. Objetos tipados sobre el contrato de 5 datos, paginación automática y errores honestos. El cliente propio de la API.

import brubru

bru = brubru.Client(api_key="brubru_live_...")
items = bru.extract("https://cinea.ec.europa.eu/news_en", classify=True)
posts = bru.social.posts(entity_type="commissioner", platform="x")

eurovoc: un clasificador EuroVoc independiente y de código abierto. Etiqueta cualquier texto en el espacio temático oficial de la UE (7.029 descriptores, 127 microtesauros, 21 dominios), multilingüe incluido el catalán. Un sucesor moderno del paquete PyEuroVoc de 2021.

import eurovoc

eurovoc.classify("Markets in crypto-assets regulation")
# -> [{"descriptor": "financial instrument", "mt": "2426", "domain": "24", "score": 0.88}, ...]
