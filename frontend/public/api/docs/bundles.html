A route can sit in several bundles: an agency's news is both Agencies and News. Every data route sits in at least one.

Find the routes in a bundle

In the browser: the API Console narrows its catalogue to one bundle, with no account.

From code: both routes are public and free, and need no key.

curl https://brubru-production.up.railway.app/api/v2/bundles
curl https://brubru-production.up.railway.app/api/v2/bundles/funding-procurement

The OpenAPI spec names each route's bundles in x-brubru-bundles.

Limit a key to bundles

When you create a key, choose "Only the bundles I choose". The key is then refused on anything else, with the error route_not_included, and routes added later join their bundle by themselves. The price of a call does not change.

A key limited to bundles does not open the MCP tools, because a tool reaches further than any one bundle. For those, create a key with every route.
