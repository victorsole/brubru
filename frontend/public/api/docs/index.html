Brubru EU Data API · v1 · 92+ endpoints across 37 folders

The EU, structured.

Brubru is a vertical EU data provider. Our REST API gives developers, RegTech platforms, public-affairs teams, and AI agents programmatic access to 28,505 adopted EU laws, 1,717 legislative procedures in flight, 14,873 EU officials across every institution, 56,051 amendments, 1,026 EP reports, 386 tenders (TED), 210 research publications (EPRS, STOA, JRC, ART, ECA), 528 Commission Register documents, 227 curated policy guides, live commissioner agendas, EP webstreams, the legal-text intelligence layer that powers Brubru's own chatbot and Amendator, and a new specialised EC databases folder covering 10 institutional surfaces no other vendor exposes through a single API key: 6,002 CFSP-sanctioned persons/entities, 17,247 Transparency Register lobbyist orgs, 83,807 comitology documents, 5,917 Geographical Indications, 900 international agreements, 675 trade-defence measures, live DG COMP competition cases (~250k upstream), 3,543 JRC datasets, 1,451 DG REGIO cohesion datasets, and live Combined Nomenclature lookup. The same data we use internally is what you call. Brubru is the first customer of its own API.

New to APIs? An API is a way for your software to talk to Brubru's software over the internet. You send an HTTP request (like a web browser does), we send back JSON (structured data). The rest of these docs explain how.

Article 290 TFEU acts adopted under powers delegated by Parliament and Council.
Implementing acts
Article 291 TFEU acts ensuring uniform implementation of EU law across Member States.
TRIS notifications
Member State draft technical regulations notified under Directive 2015/1535.
Commission Register
528 Commission preparatory documents (COM, SWD, JOIN, C) with EUR-Lex CELEX-derived PDF URLs.
Council Documents
Council of the EU public register documents (presidency notes, working party reports, conclusions).

Specialised EC databases (10 folders, NEW May 2026)

Ten institutional surfaces no other vendor exposes through a single API key. Each cluster is also wired into the Brubru chatbot — when a user asks about lobbyists, sanctions, or anti-dumping duties, the chat retrieves directly from these tables.

Sanctions (CFSP)
6,002 persons + entities on the EU consolidated CFSP list. Programmes (IRN, RUS, UKR, BLR, SYR, PRK, MMR, TERR), legal basis, citizenships, date_file.
Transparency Register
17,247 registered lobbyist organisations. Original name, acronym, registration category, head office country, EP-pass count, FTEs, declared lobbying costs.
Comitology documents
83,807 documents from the Comitology Register: voting sheets, summary records, draft implementing acts, opinions. Filter by committee code (e.g. SCoPAFF C20407, Appeal Committee C39800).
Geographical Indications
5,917 EU-protected names — PDO, PGI, TSG, wine, spirit drinks, craft. Sourced from eAmbrosia (DG AGRI authoritative) + EUIPO GIview union register. Filter by type, country, status.
International agreements
900 EU international agreements: FTA, EPA, AA, PCA, Fisheries, Aviation. CELEX sector-2 type-A, with partner, agreement type, in-force flag.
Trade defence
675 anti-dumping, countervailing, and safeguard measures. CELEX sector-3 type-R, with measure type, duty status, target country, product, in-force flag.
DG COMP cases (live)
Live pass-through to api.tech.ec.europa.eu/search-api — ~250k competition cases (state aid SA., antitrust AT., mergers M.). Cases by member state, aid category, instrument.
JRC Data Catalogue
3,543 scientific datasets from the Joint Research Centre: ESDAC, EFFIS, GHSL, LUISA, JRC AI Watch, JRC EDGAR-FOOD. Title, description, publisher, EuroVoc keywords.
DG REGIO cohesion data
1,451 Socrata-catalogued cohesion datasets from cohesiondata.ec.europa.eu — ESF+, ERDF, Cohesion Fund, Just Transition Fund, Interreg, RRF beneficiaries.
CN codes (Access2Markets, live)
Live pass-through to webgate.ec.europa.eu/nomen — Combined Nomenclature sections and product trees for tariff/customs classification.

Authentication at a glance

Every /api/v1/* call requires an API key passed either as a Bearer token or an X-API-Key header:

curl -H "Authorization: Bearer brubru_live_..." \
  "https://brubru-production.up.railway.app/api/v1/laws?q=artificial+intelligence&limit=5"

Response envelope at a glance

Every paginated endpoint returns the same shape. Code once against this envelope and swap datasets by changing the path:

{
  "total": 139,
  "returned": 20,
  "pages": 7,
  "page": 1,
  "limit": 50,
  "has_more": true,
  "next_page": 2,
  "remaining_pages": 6,
  "coverage_complete": true,
  "published_from": "2026-01-01",
  "published_to": "2026-01-31",
  "published_end": "2026-01-31",
  "detail_level": "Full",

Quickstart: your first call

1. Get an API key. Email hello@beresol.eu once you're on the Professional subscription. Keys look like brubru_live_ followed by 48 hex characters.

2. Make a call.

curl -H "Authorization: Bearer $BRUBRU_API_KEY" \
  "https://brubru-production.up.railway.app/api/v1/ping"

Response (this one's public, no auth required):

{
  "status": "ok",
  "service": "brubru-data-provider",
  "version": "v1",
  "time": "2026-04-20T15:00:00Z"
}

3. Try a real search.

curl -H "Authorization: Bearer $BRUBRU_API_KEY" \
  "https://brubru-production.up.railway.app/api/v1/laws?q=artificial+intelligence&limit=3"

You get a paginated list of EU laws matching "artificial intelligence", with CELEX identifiers, titles, dates, and EUR-Lex URLs. From there every other endpoint follows the same envelope pattern.

Limitations (what we don't cover)

  • Non-EU legislation. We don't track national gazettes directly. If you need Spanish BOE + EU together, pair us with GovClipping or similar.
  • Real-time push. No webhooks or SSE yet. Polling on our refresh cadence is the integration pattern. Webhooks on the September 2026 roadmap.
  • Languages. API responses are English today. Some law texts are available in all 24 EU languages via the Cellar fallback but the structured responses are English-only. Multilingual endpoints in September 2026.
  • Bulk exports. No nightly CSV/Parquet dumps yet. Roadmap September 2026. For now, iterate paginated lists.
  • National parliaments. We don't ingest from national parliaments. EP only.
