Brubru EU Data API · v2 · 935 endpoints sur 88 dossiers d'institutions de l'UE

L'UE, structurée.

Brubru est un fournisseur vertical de données de l'UE. Notre API REST donne aux développeurs, plateformes RegTech, équipes d'affaires publiques et agents d'IA un accès programmatique à 8 710 actes de l'UE adoptés (28 513 publications du JO), 2 080 dossiers législatifs suivis, 16 521 fonctionnaires de l'UE, tous les députés, 58 399 amendements du PE, les registres du Parlement / Conseil / Conseil européen / Eurogroupe / Commission, la Banque centrale européenne et les institutions financières de l'UE, les agences décentralisées de l'UE (médicaments, sécurité alimentaire, environnement, produits chimiques, drogues, droits fondamentaux et plus), financements et appels d'offres de l'UE, les 19 modèles d'application aux fonds européens de Tender Docs de Brubru, données ouvertes incluant 12 séries Eurostat curées sur le sport et la santé liée au fitness servies en direct et l'intelligence propre de Brubru sur l'UE. Les mêmes données que nous utilisons en interne sont celles que vous appelez. Brubru est le premier client de sa propre API.

Une seule surface, une seule clé. L'API est organisée comme l'UE elle-même: un dossier par institution ou organe, 88 dossiers au total, 935 endpoints. Parcourez les dossiers ci-dessous ou ouvrez la référence complète et toujours à jour de l'API →: chaque endpoint déployé, généré en direct depuis la spécification OpenAPI.

Nouveau dans les API ? Une API permet à votre logiciel de dialoguer avec celui de Brubru sur internet. Vous envoyez une requête HTTP (comme un navigateur) et nous renvoyons du JSON (des données structurées). Le reste de cette documentation explique comment.

L'authentification en un coup d'œil

Chaque appel à /api/v2/* exige une clé d'API envoyée en token Bearer ou en en-tête X-API-Key :

curl -H "Authorization: Bearer brubru_live_..." \
  "https://brubru.beresol.eu/api/v2/legislative/eur-lex/laws?q=artificial+intelligence&limit=5"

Détails complets dans Authentification.

L'enveloppe de réponse en un coup d'œil

Chaque endpoint paginé renvoie la même forme. Programmez une fois contre cette enveloppe et changez de jeu de données en changeant le chemin :

{
  "total": 139,
  "returned": 20,
  "pages": 7,
  "page": 1,
  "limit": 50,
  "has_more": true,
  "next_page": 2,
  "remaining_pages": 6,
  "coverage_complete": true,
  "published_from": "2026-01-01",
  "published_to": "2026-01-31",
  "published_end": "2026-01-31",
  "detail_level": "Full",
  "data": [ ... ]
}

La provenance et les informations de limite de débit vivent dans les en-têtes de réponse, pas dans le corps :

X-Powered-By: Brubru
X-Source: brubru.beresol.eu
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 58
X-RateLimit-Tier: free

Démarrage rapide : votre premier appel

1. Obtenez une clé d'API. Écrivez à hello@beresol.eu une fois l'abonnement Professional souscrit. Les clés ont la forme brubru_live_ suivi de 48 caractères hexadécimaux.

2. Vérifiez que le service répond. Le contrôle de santé est public: aucune clé requise :

curl "https://brubru.beresol.eu/health"

Réponse :

{
  "status": "ok",
  "service": "brubru-data-provider",
  "time": "2026-04-20T15:00:00Z"
}

3. Essayez une vraie recherche.

curl -H "Authorization: Bearer $BRUBRU_API_KEY" \
  "https://brubru.beresol.eu/api/v2/legislative/eur-lex/laws?q=artificial+intelligence&limit=3"

Vous obtenez une liste paginée d'actes de l'UE correspondant à "artificial intelligence", avec identifiants CELEX, titres, dates et URL EUR-Lex. À partir de là, chaque endpoint suit le même modèle d'enveloppe: changez simplement le chemin.

Limites (ce que nous ne couvrons pas)

  • Législation non européenne. Nous ne suivons pas directement les journaux officiels nationaux. Si vous avez besoin du BOE espagnol et de l'UE ensemble, associez-nous à GovClipping ou similaire.
  • Notification en temps réel. Pas encore de webhooks ni de SSE. L'intégration se fait par interrogation selon notre fréquence. Webhooks prévus pour septembre 2026.
  • Langues. Les réponses de l'API sont en anglais aujourd'hui. Certains textes juridiques sont disponibles dans les 24 langues de l'UE via Cellar, mais les réponses structurées sont en anglais uniquement. Endpoints multilingues en septembre 2026.
  • Exports en masse. Pas encore de vidages nocturnes CSV/Parquet. Prévu pour septembre 2026. Pour l'instant, parcourez les listes paginées.
  • Parlements nationaux. Nous n'ingérons pas les parlements nationaux. PE uniquement.

Bibliothèques clientes

Deux bibliothèques Python officielles, désormais sur PyPI et open source (MIT), sur github.com/Beresol-BV/brubru-EU-scraper-library. Installez-les avec pip :

pip install brubru
pip install "brubru-eurovoc[local]"   # [local] adds the classifier model

brubru : un SDK Python léger au-dessus de l'API v2. Objets typés sur le contrat à 5 données, pagination automatique et erreurs honnêtes. Le client maison de l'API.

import brubru

bru = brubru.Client(api_key="brubru_live_...")
items = bru.extract("https://cinea.ec.europa.eu/news_en", classify=True)
posts = bru.social.posts(entity_type="commissioner", platform="x")

eurovoc : un classifieur EuroVoc autonome et open source. Il étiquette n'importe quel texte dans l'espace thématique officiel de l'UE (7 029 descripteurs, 127 microthésaurus, 21 domaines), multilingue y compris le catalan. Un successeur moderne du paquet PyEuroVoc de 2021.

import eurovoc

eurovoc.classify("Markets in crypto-assets regulation")
# -> [{"descriptor": "financial instrument", "mt": "2426", "domain": "24", "score": 0.88}, ...]

Téléchargez les paquets déjà construits :

  • brubru on PyPI · wheel · source
  • brubru-eurovoc on PyPI · wheel · source
  • github.com/Beresol-BV/brubru-EU-scraper-library
