L'UE, structurée.

Brubru est un fournisseur de données de l'UE. Notre API REST donne aux développeurs, plates-formes RegTech, équipes d'affaires publiques et agents IA un accès programmatique à 8 710 lois de l'UE adoptées (28 513 publications au JO), 1 717 procédures législatives en cours, 14 873 fonctionnaires de l'UE dans chaque institution, 56 051 amendements, 1 026 rapports du PE, 386 marchés publics (TED), 210 publications de recherche (EPRS, STOA, JRC, ART, ECA), 528 documents du Registre de la Commission, 227 guides de politique curatisés, agendas de commissaires en direct, webdiffusions du PE, la couche d'intelligence de texte législatif qui alimente le chatbot et l'Amendator de Brubru, et un nouveau dossier de bases de données spécialisées de la CE couvrant 10 surfaces institutionnelles qu'aucun autre fournisseur n'expose via une seule clé API : 6 002 personnes/entités sanctionnées par la PESC, 17 247 organisations de lobbying au Registre de la Transparence, 83 807 documents de comitologie, 5 917 Indications Géographiques, 900 accords internationaux, 675 mesures de défense commerciale, cas de concurrence live de la DG COMP (~250k en amont), 3 543 ensembles de données du JRC, 1 451 ensembles de données de cohésion de la DG REGIO, et recherche de nomenclature combinée en direct. Les mêmes données que nous utilisons en interne sont celles que vous appelez. Brubru est le premier client de sa propre API.

Nouveau : API v2 réorganise tout autour des institutions de l'UE, un dossier par organisme, et ajoute les bases de données institutionnelles qu'aucun autre fournisseur n'expose — les registres du Parlement (déclarations des députés au PE, assistants accrédités, analyses de soutien des commissions), les régimes de sanctions du Conseil, les bases de données des agences de l'UE (médicaments, ensembles de données de sécurité alimentaire, indicateurs environnementaux, la liste des candidats SVHC REACH, la bibliothèque des drogues, la jurisprudence des droits fondamentaux et la Charterothèque), et plus. Voir la documentation complète et toujours à jour de l'API → — tous les points de terminaison déployés, rendus en direct à partir de la spécification OpenAPI.

Nouveau pour les API ? Une API est un moyen pour votre logiciel de communiquer avec celui de Brubru sur Internet. Vous envoyez une requête HTTP (comme le ferait un navigateur Web), nous renvoyons du JSON (données structurées). Le reste de cette documentation explique comment.

Bases de données spécialisées de la CE (10 dossiers, NOUVEAU mai 2026)

Dix surfaces institutionnelles qu'aucun autre fournisseur n'expose via une seule clé API. Chaque cluster est également câblé dans le chatbot Brubru — lorsqu'un utilisateur pose des questions sur les lobbies, les sanctions ou les droits antidumping, le chat récupère directement à partir de ces tables.

Sanctions (PESC)

Registre de la Transparence
17 247 organisations de lobbying inscrites. Nom d'origine, acronyme, catégorie d'inscription, pays du siège, nombre de cartes PE, FTE, coûts de lobbying déclarés.
Documents de comitologie
83 807 documents du Registre de comitologie : feuilles de vote, résumés, projets d'actes d'exécution, avis. Filtrer par code de comité (p. ex. SCoPAFF C20407, Comité d'appel C39800).
Indications Géographiques
5 917 noms protégés par l'UE — AOP, IGP, STG, vins, boissons spiritueuses, artisanat. Provenant d'eAmbrosia (DG AGRI faisant autorité) + registre d'union GIview EUIPO. Filtrer par type, pays, statut.
Accords internationaux
900 accords internationaux de l'UE : ALE, APE, AA, PCA, Pêche, Aviation. CELEX secteur-2 type-A, avec partenaire, type d'accord, drapeau en vigueur.
Défense commerciale
675 mesures antidumping, mesures de compensation et mesures de sauvegarde. CELEX secteur-3 type-R, avec type de mesure, statut des droits, pays cible, produit, drapeau en vigueur.
Cas de concurrence DG COMP (en direct)
Transfert direct vers api.tech.ec.europa.eu/search-api — ~250k cas de concurrence (aide d'État SA., ententes AT., fusions M.). Cas par État membre, catégorie d'aide, instrument.
Catalogue de données JRC
3 543 ensembles de données scientifiques du Centre de recherche commun : ESDAC, EFFIS, GHSL, LUISA, JRC AI Watch, JRC EDGAR-FOOD. Titre, description, éditeur, mots clés EuroVoc.
Données de cohésion DG REGIO
1 451 ensembles de données catalogués par Socrata à partir de cohesiondata.ec.europa.eu — FSE+, FEDER, Fonds de cohésion, Fonds pour une transition juste, Interreg, bénéficiaires du RRF.
Codes CN (Access2Markets, en direct)

Authentification en un coup d'oeil

Chaque appel /api/v1/* nécessite une clé API transmise soit comme token Bearer, soit comme en-tête X-API-Key :

curl -H "Authorization: Bearer brubru_live_..." \
  "https://brubru-production.up.railway.app/api/v1/laws?q=artificial+intelligence&limit=5"

Enveloppe de réponse en un coup d'oeil

Chaque point de terminaison paginé renvoie la même forme. Codez une fois contre cette enveloppe et permutez les ensembles de données en modifiant le chemin :

{
  "total": 139,
  "returned": 20,
  "pages": 7,
  "page": 1,
  "limit": 50,
  "has_more": true,
  "next_page": 2,
  "remaining_pages": 6,
  "coverage_complete": true,
  "published_from": "2026-01-01",
  "published_to": "2026-01-31",
  "published_end": "2026-01-31",
  "detail_level": "Full",
  "data": [ ... ]
}

L'information de provenance et les limites de débit vivent sur les en-têtes de réponse, pas dans le corps :

X-Source: brubru.beresol.eu
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 58
X-RateLimit-Tier: free

Démarrage rapide : votre premier appel

1. Obtenez une clé API. Envoyez un e-mail à hello@beresol.eu une fois que vous êtes abonné à la version Professionnelle. Les clés ressemblent à brubru_live_ suivi de 48 caractères hexadécimaux.

2. Effectuez un appel.

curl -H "Authorization: Bearer $BRUBRU_API_KEY" \
  "https://brubru-production.up.railway.app/api/v1/ping"

Réponse (celui-ci est public, aucune authentification requise) :

{
  "status": "ok",
  "service": "brubru-data-provider",
  "version": "v1",
  "time": "2026-04-20T15:00:00Z"
}

3. Essayez une recherche réelle.

curl -H "Authorization: Bearer $BRUBRU_API_KEY" \
  "https://brubru-production.up.railway.app/api/v1/laws?q=artificial+intelligence&limit=3"

Vous obtenez une liste paginée des lois de l'UE correspondant à « intelligence artificielle », avec les identifiants CELEX, les titres, les dates et les URLs EUR-Lex. De là, chaque autre point de terminaison suit le même modèle d'enveloppe.

Limitations (ce que nous ne couvrons pas)

  • Législation non-UE. Nous ne suivons pas les gazettes nationales directement. Si vous avez besoin du BOE espagnol + UE ensemble, associez-nous avec GovClipping ou similaire.
  • Push en temps réel. Pas encore de webhooks ou SSE. Le scrutation sur notre cadence d'actualisation est le modèle d'intégration. Webhooks au feuille de route de septembre 2026.
  • Langues. Les réponses de l'API sont en anglais aujourd'hui. Certains textes de loi sont disponibles dans les 24 langues de l'UE via le repli Cellar, mais les réponses structurées sont uniquement en anglais. Points de terminaison multilingues en septembre 2026.
  • Exports en masse. Pas encore d'exports CSV/Parquet nocturnes. Feuille de route septembre 2026. Pour l'instant, itérez sur les listes paginées.
  • Parlements nationaux. Nous n'ingérons pas des parlements nationaux. PE uniquement.
