Brubru EU Data API · v2 · 935 endpoint in 88 cartelle di istituzioni dell'UE

L'UE, strutturata.

Brubru è un fornitore verticale di dati dell'UE. La nostra API REST offre a sviluppatori, piattaforme RegTech, team di affari pubblici e agenti di IA accesso programmatico a 8.710 atti dell'UE adottati (28.513 pubblicazioni della GU), 2.080 fascicoli legislativi monitorati, 16.521 funzionari dell'UE, tutti i deputati, 58.399 emendamenti del PE, i registri di Parlamento / Consiglio / Consiglio europeo / Eurogruppo / Commissione, la Banca centrale europea e le istituzioni finanziarie dell'UE, le agenzie decentrate dell'UE (medicinali, sicurezza alimentare, ambiente, sostanze chimiche, droghe, diritti fondamentali e altro), finanziamenti e gare dell'UE, i 19 modelli di candidatura ai fondi europei di Tender Docs, dati aperti che includono 12 serie Eurostat curate su sport e salute rilevante per il fitness servite in diretta e l'intelligence propria di Brubru sull'UE. Gli stessi dati che usiamo internamente sono quelli che chiami. Brubru è il primo cliente della propria API.

Una superficie, una chiave. L'API è organizzata come l'UE stessa: una cartella per istituzione od organo, 88 cartelle in totale, 935 endpoint. Sfoglia le cartelle qui sotto, oppure apri il riferimento API completo e sempre aggiornato →: ogni endpoint distribuito, generato in tempo reale dalla specifica OpenAPI.

Nuovo alle API? Un'API è un modo per far dialogare il tuo software con quello di Brubru via internet. Tu invii una richiesta HTTP (come fa un browser) e noi restituiamo JSON (dati strutturati). Il resto di questa documentazione spiega come.

Cosa ottieni

Ogni cartella corrisponde a un'istituzione o un organo dell'UE. I conteggi sono esatti e si aggiornano man mano che l'API cresce.

L'autenticazione in breve

Ogni chiamata a /api/v2/* richiede una chiave API inviata come token Bearer o come intestazione X-API-Key:

curl -H "Authorization: Bearer brubru_live_..." \
  "https://brubru.beresol.eu/api/v2/legislative/eur-lex/laws?q=artificial+intelligence&limit=5"

La busta di risposta in breve

Ogni endpoint paginato restituisce la stessa forma. Programma una volta sola contro questa busta e cambia set di dati cambiando il percorso:

{
  "total": 139,
  "returned": 20,
  "pages": 7,
  "page": 1,
  "limit": 50,
  "has_more": true,
  "next_page": 2,
  "remaining_pages": 6,
  "coverage_complete": true,
  "published_from": "2026-01-01",
  "published_to": "2026-01-31",
  "published_end": "2026-01-31",
  "detail_level": "Full",
  "data": [ ... ]
}

La provenienza e le informazioni sul limite di frequenza vivono nelle intestazioni di risposta, non nel corpo:

X-Powered-By: Brubru
X-Source: brubru.beresol.eu
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 58
X-RateLimit-Tier: free

Avvio rapido: la tua prima chiamata

1. Ottieni una chiave API. Scrivi a hello@beresol.eu una volta attivato l'abbonamento Professional. Le chiavi hanno la forma brubru_live_ seguito da 48 caratteri esadecimali.

2. Verifica che il servizio sia attivo. Il controllo di stato è pubblico: non serve la chiave:

curl "https://brubru.beresol.eu/health"

Risposta:

{
  "status": "ok",
  "service": "brubru-data-provider",
  "time": "2026-04-20T15:00:00Z"
}

3. Prova una ricerca reale.

curl -H "Authorization: Bearer $BRUBRU_API_KEY" \
  "https://brubru.beresol.eu/api/v2/legislative/eur-lex/laws?q=artificial+intelligence&limit=3"

Ottieni un elenco paginato di atti dell'UE corrispondenti a "artificial intelligence", con identificatori CELEX, titoli, date e URL di EUR-Lex. Da lì ogni endpoint segue lo stesso schema di busta: basta cambiare il percorso.

Limiti (cosa non copriamo)

  • Legislazione extra-UE. Non seguiamo direttamente le gazzette nazionali. Se ti serve il BOE spagnolo insieme all'UE, abbinaci a GovClipping o simili.
  • Notifica in tempo reale. Ancora nessun webhook né SSE. Il modello di integrazione è il polling secondo la nostra frequenza. Webhook nella roadmap di settembre 2026.
  • Lingue. Le risposte dell'API sono oggi in inglese. Alcuni testi giuridici sono disponibili in tutte le 24 lingue dell'UE tramite Cellar, ma le risposte strutturate sono solo in inglese. Endpoint multilingue a settembre 2026.
  • Esportazioni di massa. Ancora nessun dump notturno CSV/Parquet. Roadmap settembre 2026. Per ora, scorri gli elenchi paginati.
  • Parlamenti nazionali. Non acquisiamo dai parlamenti nazionali. Solo il PE.

Librerie client

Due librerie Python ufficiali sono in sviluppo per mettere l'API e il suo classificatore EuroVoc a un solo import di distanza. L'API REST è già attiva: integrati con gli endpoint nel frattempo. Entrambe sono contrassegnate come in sviluppo.

brubru: un SDK Python leggero sopra l'API v2. Oggetti tipizzati sul contratto a 5 dati, paginazione automatica ed errori onesti. Il client ufficiale dell'API.

import brubru

bru = brubru.Client(api_key="brubru_live_...")
items = bru.extract("https://cinea.ec.europa.eu/news_en", classify=True)
posts = bru.social.posts(entity_type="commissioner", platform="x")

eurovoc: un classificatore EuroVoc autonomo e open source. Etichetta qualsiasi testo nello spazio tematico ufficiale dell'UE (7.029 descrittori, 127 microtesauri, 21 domini), multilingue compreso il catalano. Un successore moderno del pacchetto PyEuroVoc del 2021.

import eurovoc

eurovoc.classify("Markets in crypto-assets regulation")
# -> [{"descriptor": "financial instrument", "mt": "2426", "domain": "24", "score": 0.88}, ...]
