This folder is gitignored. The landing-page carousel (`landing_page.tsx`, section "CLIENTS")
references the files below by name. On a fresh clone, drop the files here manually so the
carousel renders.

| File | Client | Website |
|---|---|---|
| `bo.png` | Bo | https://hellobo.eu |
| `ferrmed.jpeg` | Ferrmed | https://www.ferrmed.com/ |
| `movimentgaudi.png` | Moviment Gaudí | https://movimentgaudi.cat/en/ |
| `tas.png` | TAS Europrojects | https://www.taseuro.com/ |
| `govclipping.png` | GovClipping (partner) | — |

If a logo is missing the carousel will show a broken-image icon for that slot. Add the file
to fix it locally; never commit logos to the repo.
