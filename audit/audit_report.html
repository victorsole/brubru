SPA-cracking via Playwright headless Chromium: five SPAs that previously blocked our scrapers were cracked over the same window — Comitology Register (/core/api/front/ path discovered via Playwright network capture), DG COMP (api.tech.ec.europa.eu with public CS_PROD_ODSE_PROD key), Access2Markets (webgate.ec.europa.eu/flows + nomen API), JRC Data Catalogue (data.europa.eu federation, after Imperva blocked all direct paths), and eAmbrosia (webgate.ec.europa.eu/eambrosia-api).

End-to-end verification: 10/10 cluster intent detectors fire on one positive query each, 0/6 false positives on negative queries (e.g. "What is the AI Act?" does not light up any of the 10 narrow intents). Commits 630d3db7 (sanctions + TR + comitology) and 0f91afe3 (the remaining 7) shipped to Railway 11 May.

Three bug-fixes surfaced during testing (all closed before deploy):

  • ESF+ regex word-boundary failure — trailing \b after literal + never matches because the position is non-word/non-word. Rewrote to anchor \b only around alphanumerics.
  • Trade Defence demonym gap — natural-language queries like "anti-dumping on Chinese e-bikes" did not resolve to canonical column values ("People's Republic of China", "bicycle"). Added a demonym + product-synonym expansion map (Chinese → china, e-bike → bicycle, etc.) so the ILIKE search hits.
  • CN section lookup over-strict — the public /nomen/public/v2/nomenclature/products endpoint only exposes the 21 top-level CN sections. Switched from substring match to token-overlap scoring against section descriptions, with goods-keyword expansion (olive/oil → fats, oils).

Also fixed at the same time: 2 KB guides (ertms_deployment_2030.md, ten_t_regulation_2024_1679.md) whose triggers had been registered in knowledge_loader.py on 11 May (commit d1a18d91) but whose content files had never been committed — 39 orphan triggers pointing to non-existent guides. Commit 72e18b1b closed the loop.
