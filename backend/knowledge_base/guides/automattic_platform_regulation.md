## CORE REGULATORY STACK — multi-product exposure
- **Digital Services Act** (Reg 2022/2065, CELEX 32022R2065) — WordPress.com + Tumblr are hosting providers. WordPress.com near-VLOP in some metrics. Tumblr's 2018 adult content ban was a pre-DSA content-moderation precedent.
- **Copyright in DSM Art 17** (Dir 2019/790, CELEX 32019L0790) — WordPress.com VIP + Tumblr UGC. OCSSP liability in scope.
- **AI Act** (Reg 2024/1689, CELEX 32024R1689) — Jetpack AI, WordPress.com AI assistants, Elementor integrations (GPAI deployment disclosures).
- **NIS2 Directive** (Dir 2022/2555, CELEX 32022L2555) — WordPress.com + VIP as cloud hosting providers (Annex I Sector 8).
- **Cyber Resilience Act** (Reg 2024/2847, CELEX 32024R2847) — Jetpack plugin, WooCommerce extension, WordPress core distribution = products with digital elements.
- **P2B Regulation** (Reg 2019/1150, CELEX 32019R1150) — WordPress.com + WooCommerce business merchants.
- **Digital Content Directive** (Dir 2019/770, CELEX 32019L0770) — WordPress.com Business/eCommerce/Enterprise paid plans.
- **Data Act** (Reg 2023/2854, CELEX 32023R2854) — WooCommerce + Jetpack + WordPress.com data portability; cloud-switching provisions affect Automattic's own AWS/GCP procurement.
- **PSD2 + eIDAS** — WooCommerce Payments; digital signatures in forms.
- **MiCA** (Reg 2023/1114) — if WooCommerce crypto add-ons classify as CASP activity.
- **GDPR** (Reg 2016/679, CELEX 32016R0679) — WordPress plugin ecosystem cascades controller/processor responsibility onto site owners; Automattic as service provider + Jetpack as data-processor hybrid.
- **CSAM Regulation** (COM(2022) 209) — Tumblr's adult-content ban and WordPress.com's abuse workflows pre-position them for detection obligations if adopted.
- **TERREG** (Reg 2021/784, CELEX 32021R0784) — via GIFCT membership, TERREG hash-sharing is already operational.
- **AVMSD** (Dir 2018/1808, CELEX 32018L1808) — VideoPress, WordPress.com video hosting.
- **eIDAS 2** (Reg 2024/1183, CELEX 32024R1183) — EUDI Wallet integration for WordPress.com accounts.
- **Representative Actions** (Dir 2020/1828, CELEX 32020L1828).
- **European Accessibility Act** (Dir 2019/882, CELEX 32019L0882) — WordPress.com paid plans; accessibility features long a WordPress core commitment.
- **Digital Fairness Act** — subscription / checkout dark patterns.
