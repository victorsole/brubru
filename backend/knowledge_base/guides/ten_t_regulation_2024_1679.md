## Network architecture

The recast simplifies the previous two-layer model (Core 2030 + Comprehensive 2050) into a **three-layer network** with intermediate deadlines:

| Layer | Deadline | Scope |
|---|---|---|
| **Core Network** | 31 December 2030 | Most strategically important nodes + links across all transport modes |
| **Extended Core Network** | 31 December 2040 | Densifies the Core Network — additional corridors and connections |
| **Comprehensive Network** | 31 December 2050 | Full EU coverage — every region connected |

## 9 European Transport Corridors

The recast renames "Core Network Corridors" as **European Transport Corridors** (ETCs) and reorganises them:

1. **Atlantic** — Algeciras → Madrid → Lisbon → Bordeaux → Paris → Mannheim → Strasbourg
2. **Baltic Sea-Adriatic Sea** — Helsinki → Tallinn → Warsaw → Vienna → Ljubljana → Trieste/Ravenna
3. **Baltic Sea-Black Sea-Aegean Sea** — Tallinn → Riga → Vilnius → Warsaw → Lviv (UA) → Kosice (SK) → Budapest → Sofia → Thessaloniki
4. **Mediterranean** — Algeciras/Almería/Cartagena/Valencia/Barcelona → Marseille → Genoa/Milan/Verona → Ljubljana → Budapest → Lviv (UA). **Direct overlap with FerrMed Mediterranean Corridor.**
5. **North Sea-Alpine** — Edinburgh/Manchester/Liverpool/Bristol → London → Calais/Dunkirk → Lille → Brussels → Aachen → Cologne → Frankfurt → Mannheim → Basel → Lyon/Geneva → Marseille
6. **North Sea-Baltic** — Helsinki → Tallinn → Riga → Kaunas → Warsaw → Berlin → Hamburg → Amsterdam/Rotterdam → Antwerp
7. **North Sea-Rhine-Mediterranean** — Cork → Dublin → Liverpool → Manchester → Birmingham → London → Brussels → Cologne → Frankfurt → Strasbourg → Lyon → Marseille
8. **Rhine-Danube** — Strasbourg → Mannheim → Frankfurt → Würzburg → Nuremberg → Regensburg → Vienna → Bratislava → Budapest → Bucharest → Constanta
9. **Western Balkans-Eastern Mediterranean** — Hamburg → Berlin → Prague → Vienna → Budapest → Belgrade → Sofia/Skopje → Athens/Thessaloniki

The **Mediterranean Corridor** (#4) is the file FerrMed has worked on continuously since 2004.

## Standards required by 2030 (Core Network)

For rail freight specifically:

- **Track gauge**: 1,435 mm (standard European gauge) **or interoperable with that gauge** — major issue for Iberian peninsula 1,668 mm and Finnish/Baltic 1,520 mm networks. Mediterranean Corridor migration plan to 1,435 mm is in flight.
- **Loading gauge**: P400 (intermodal-compatible)
- **Train length**: 740 metres **minimum** for freight trains
- **Axle load**: 22.5 tonnes
- **Electrification**: 25 kV AC + ETCS (ERTMS Level 2 or Level 3)
- **Speed**: 100 km/h freight, 160 km/h passenger
- **TAF/TAP TSI**: full Telematics Applications for Freight + Passengers compliance

## Funding

The TEN-T Regulation is the policy framework; the **Connecting Europe Facility (CEF) Regulation 2021/1153** is the funding instrument. CEF Transport carries €33.7 billion for 2021-2027, ring-fenced as:
- €25.81 billion General Envelope (open to all Member States)
- €11.29 billion Cohesion Envelope (only Cohesion-eligible Member States)
- €1.69 billion Military Mobility (dual-use)

See `cef_transport_funding.md` for the funding mechanism.

## Cross-border streamlining (Directive 2021/1187)

Adopted alongside the TEN-T recast: **Directive (EU) 2021/1187** (CELEX 32021L1187) on streamlining permitting for cross-border railway projects. Sets a **4-year cap** for permit-granting procedures on TEN-T core network projects. Member State transposition deadline was 10 August 2023; Commission infringement audit ongoing.
