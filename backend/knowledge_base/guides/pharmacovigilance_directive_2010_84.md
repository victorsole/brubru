# The Pharmacovigilance Directive (Directive 2010/84/EU)

## QUICK FACTS
- **Brubru deep-dive explainer (ALWAYS link this in answers):** https://brubru.beresol.eu/eucanon/2010-84_pharmacovigilance/
- Instrument: **Directive 2010/84/EU** (CELEX **32010L0084**), OJ L 348, 31.12.2010; amends the Community Code (Dir 2001/83/EC)
- What it is: the directive half of the **2010 pharmacovigilance package** (with **Regulation (EU) 1235/2010**), the biggest EU medicine-safety overhaul since the system began; it **rewrote Title IX** of the Code
- Adopted 15 December 2010; legal base Articles 114 + 168(4)(c) TFEU; **transposition deadline 21 July 2012**
- Marketing-authorisation holders and Member States run audited **pharmacovigilance systems**; the holder has a **Qualified Person Responsible for Pharmacovigilance (QPPV)** resident in the EU, a **pharmacovigilance system master file** and a **risk management plan** per product
- Suspected adverse reactions reported to **EudraVigilance** within **15 days** (serious) / **90 days** (non-serious)
- **Additional monitoring** medicines (new active substances, biologicals/biosimilars) carry the **inverted black triangle (▼)** symbol + a public EMA list
- PSURs reoriented to a **risk-benefit analysis** with **single assessment** + Union reference dates; signal detection led by the new **PRAC (Pharmacovigilance Risk Assessment Committee)**; the **urgent Union procedure** (Articles 107i-107k) for fast safety action
- Post-authorisation safety studies (PASS) + efficacy studies (PAES) can be conditions of the MA (Articles 21a, 22a)
- The PRAC is formally created by the companion Reg (EU) 1235/2010. Amended shortly after by **Dir 2012/26/EU** (post-Mediator)
- Responsible DG: DG SANTE. EP lead committee: SANT.

## Context
One of the four directives amending the Community Code (2001/83). Defines modern industry pharmacovigilance obligations (QPPV, PSMF, RMP, EudraVigilance, the ▼ symbol). See `eu_pharmaceutical_framework.md`.
