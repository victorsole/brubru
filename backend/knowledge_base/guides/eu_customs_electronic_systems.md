# EU Customs Electronic Systems

## QUICK FACTS
Legal basis: Union Customs Code (Regulation (EU) No 952/2013), CELEX: 32013R0952
Implementing act: Commission Implementing Decision (EU) 2019/2151 (Work Programme), CELEX: 32019D2151
Lead DG: DG TAXUD
Deadline: UCC electronic systems full deployment by 31 December 2025 (extended)
Reform: Customs reform proposal COM(2023) 258, CELEX: 52023PC0258

## Overview

The EU customs union relies on a network of interconnected electronic systems for processing customs declarations, managing risk, and facilitating trade. These systems are mandated by the Union Customs Code (UCC) and implemented through the Multi-Annual Strategic Plan (MASP) and UCC Work Programme.

## Key Electronic Systems

### Currently Operational

| System | Purpose | Status |

| AES/ECS | Automated Export System / Export Control System | Operational |
| CDS | Customs Decisions System (authorisations, BTI, BOI) | Operational |
| SURV3 | Surveillance system for import/export statistics | Operational |

| REX | Registered Exporter System (rules of origin) | Operational |

| PoUS | Proof of Union Status | Deployed 2024 |
| GUM | Guarantee Management System | Deploying |

### Customs Data Hub (proposed)

The 2023 customs reform proposal (COM(2023) 258) introduces the EU Customs Data Hub, a centralised platform to:
- Replace multiple legacy systems with a single data environment
- Enable real-time risk analysis using AI and machine learning
- Provide a single window for traders to submit all customs data
- Integrate with other border management systems (SIS, EES, ETIAS)

Timeline: Phased implementation 2028-2032 if adopted.

### ICS2 (Import Control System 2)

The most significant current deployment. Three releases:
- Release 1 (2021): Postal and express carriers, pre-loading ENS data
- Release 2 (2023): Air cargo, general aviation
- Release 3 (2024-2025): Maritime, rail, road transport

ICS2 collects Entry Summary Declaration (ENS) data before goods arrive in the EU for security risk analysis. It introduces the Common Repository for pre-arrival data sharing between customs authorities.

## UCC Work Programme (MASP)

Commission Implementing Decision (EU) 2019/2151 establishes the deployment schedule for all UCC electronic systems. The Work Programme has been amended multiple times to extend deadlines.

Key milestones:
- 2020: CDS, REX, SURV3 deployed
- 2023-2024: NCTS Phase 5, ICS2 Release 2
- 2024-2025: ICS2 Release 3, PoUS, GUM
- 2025: Full UCC electronic deployment deadline (some extensions granted)

## Customs Reform 2023

The Commission proposed a comprehensive customs reform package on 17 May 2023:
- Regulation establishing the EU Customs Authority and EU Customs Data Hub: COM(2023) 258
- CELEX: 52023PC0258
- Procedure: 2023/0156(COD)
- EP Lead Committee: IMCO
- Key features: EU Customs Authority (Lyon), Trust and Check traders, simplified e-commerce rules, single data submission
