## Off The Radar — Brussels, 23 June 2026 — Attendee Dossier

The raw attendee export below was reorganised on 16 June 2026 with light Tavily/WebFetch enrichment. The reorganisation is built around **one operating thesis**: Brubru's Tenderator is a deep funding/procurement layer; what these startups need is for Tenderator to **link out cleanly to MEUB (tracking), Chat (Q&A), and EU Law Comply (audit)**, NOT for Tenderator to grow new sub-features that duplicate those products.

### Brubru hand-off matrix — what Tenderator should deepen, where it should hand off

| Pain a startup has on day 1 | Lives in Tenderator | Hands off to | Why it's a hand-off, not a sub-feature |
|---|---|---|---|
| "What can I apply to right now?" | Funding panel, TED, EIC sub-chips, EIB | — | This IS Tenderator's core. |
| "Who won the last cycle?" | EIC Fund portfolio panel, F&T projects | — | Lives in Tenderator drawer. |
| "What's the upcoming deadline I just bookmarked?" | Save-to-track button | **MEUB → Tenders sub-tab** | MEUB already has the personal tracking + reminder layer. |
| "Does my product trigger the AI Act / NIS2 / MDR / Data Act?" | Programme metadata flags the regime | **EU Law Comply** | Comply already runs the full audit + obligation list. |
| "What does this Annex III line actually require?" | "Ask Brubru" button on the tender card | **Chat with KB injection** | Chat already has the 128 knowledge guides. |
| "I need the OEIL procedure context behind this call" | Procedure ID surfaced | **MEUB → Legislative Tracker** | MEUB already tracks 1,296 procedures. |
| "Is this DG MARE / DG ENER / DG DIGIT call active?" | EU Calendar event linked | **MEUB → My EU Calendar** | Calendar already aggregates 6 sources. |
| "What's the regulatory news on this sector this week?" | Sector chip → news pivot | **MEUB → News / Dashboard** | MEUB already aggregates 44 news portals. |
| "I need to draft an amendment to this proposal" | Link from a COD proposal in the feed | **Amendator** | Amendator already does Akoma Ntoso XML editing. |
| "Generate a 1-pager for my Horizon application" | "Generate brief" CTA on a call card | **Document Generator** | `/api/generate/*` already exists. |

The five things to deepen in Tenderator (not duplicate elsewhere):

1. **Make every tender card link to its companion law in EU Law Comply**, not just to the regulation PDF. If a TED notice is published under Defence Regulation 2009/81/EC, the card surfaces "Run Comply on Defence Procurement Directive" as a one-click CTA.
2. **Mirror the EIC Fund portfolio drawer panel to Horizon, IHI, EU4Health, EDF projects** — same "who won the last cycle" pattern, different data table (F&T projects, 109k rows).
3. **Sector lens that sets a context for the next 3 products visited**: clicking "Healthtech" in Tenderator pre-loads the same lens in MEUB News and Chat ("answer with MDR-aware framing"). One sector pick = three products configured.
4. **Save-to-track from Tenderator writes a row to MEUB's tender tracking table** (already exists, migration 041 archive layer). Today the link is loose. Need a single save action.
5. **"Generate a 1-pager" button on every EIC/Horizon call card** pipes the call metadata into `/api/generate/funding-brief` (the Document Generator endpoint). Doesn't exist yet; near-zero new code.

These deepen Tenderator's navigation; they don't grow new product surfaces.

## Off The Radar — Brussels, 23 June 2026 — Attendee Dossier

The raw attendee export below was reorganised on 16 June 2026 with light Tavily/WebFetch enrichment. The reorganisation is built around **one operating thesis**: Brubru's Tenderator is a deep funding/procurement layer; what these startups need is for Tenderator to **link out cleanly to MEUB (tracking), Chat (Q&A), and EU Law Comply (audit)**, NOT for Tenderator to grow new sub-features that duplicate those products.

The five things to deepen in Tenderator (not duplicate elsewhere):

1. **Make every tender card link to its companion law in EU Law Comply**, not just to the regulation PDF. If a TED notice is published under Defence Regulation 2009/81/EC, the card surfaces "Run Comply on Defence Procurement Directive" as a one-click CTA.
2. **Mirror the EIC Fund portfolio drawer panel to Horizon, IHI, EU4Health, EDF projects** — same "who won the last cycle" pattern, different data table (F&T projects, 109k rows).
3. **Sector lens that sets a context for the next 3 products visited**: clicking "Healthtech" in Tenderator pre-loads the same lens in MEUB News and Chat ("answer with MDR-aware framing"). One sector pick = three products configured.
4. **Save-to-track from Tenderator writes a row to MEUB's tender tracking table** (already exists, migration 041 archive layer). Today the link is loose. Need a single save action.
5. **"Generate a 1-pager" button on every EIC/Horizon call card** pipes the call metadata into `/api/generate/funding-brief` (the Document Generator endpoint). Doesn't exist yet; near-zero new code.

These deepen Tenderator's navigation; they don't grow new product surfaces.

## Roadmap for the deep-dive (one programme per session)

For each programme we'll cover, in order:

1. **Governing body** — DG, executive agency (EISMEA / ECMA / EACEA / CINEA / HADEA / ERCEA / REA / CINEA / EUSPA), or joint undertaking.
2. **Legal basis** — the establishing regulation + the latest annual work programme (AWP) CELEX.
3. **Process map** — from "call published" to "final payment / audit closure":
   - Call publication (where, what triggers it)
   - Eligibility check (who can apply)
   - Pre-registration / PIC / LEAR (the Participant Identification Code chain)
   - Application templates (Part A administrative, Part B technical, annexes)
   - Submission window + cut-off behaviour
   - Eligibility + admissibility check by the agency
   - Evaluation (experts, criteria, scoring, threshold)
   - Information letter (above/below threshold)
   - Grant Agreement Preparation (GAP) → Grant Agreement signature
   - Pre-financing payment
   - Reporting (periodic technical + financial reports, deliverables)
   - Amendments (consortium changes, scope changes, no-cost extensions)
   - Final payment + final audit
   - Communication, dissemination, IPR obligations
4. **Templates list** — every official template the user must fill, with source URL and what stage of the process it belongs to.
5. **Where each template lands in Tenderator's "Tender Docs"** — which ones we surface as scaffolds, which ones AI fills, which ones we link out to.
6. **Cross-links to MEUB Documents + EU Law Comply** — the hand-offs from this programme's docs into the legal-compliance audit (e.g. AI Act if it's a HORIZON-AI call, MDR if EU4Health medical software, AGRI eco-schemes if EAFRD).

I'm ready when you bring sources for the first programme. Suggest starting with the heaviest-traffic ones — **Horizon Europe** (everything goes through its templates) or **EIC Accelerator** (most relevant to the Off The Radar crowd we just mapped).
