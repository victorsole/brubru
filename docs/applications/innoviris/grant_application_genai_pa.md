## PART B: Technical Description

### Section 1: RELEVANCE (Evaluation Weight: 5 points)

#### 1.1 Alignment with Call Objectives

This proposal directly addresses all three priorities of the DIGITAL-2026-AI-09-GENAI-PA call:

**Priority 1 -- Scalability and Replication:**
Brubru is an operational GenAI platform already deployed for EU policy professionals. Its architecture is designed for multi-tenant deployment and can be replicated across public administrations with minimal adaptation. The platform supports 23 EU languages via its i18n framework and integrates directly with EU institutional data sources (EUR-Lex, OEIL, EP committees, Council, Commission). This proposal will package Brubru's proven components into replicable starter kits and assess replicability across administrative levels and IT environments.

**Priority 2 -- Demand Pooling:**
Through 3 years of serving EU public affairs professionals, Beresol has mapped the common GenAI needs of public administrations interacting with EU institutions: legislative tracking, policy analysis, document generation, compliance checking, and amendment drafting. This proposal will formalise these common needs into technical benchmarks, facilitating demand pooling for European GenAI solutions.

**Priority 3 -- Community Building:**
The project will establish a GenAI4PA community of practice, connecting public administrations across Member States through peer-to-peer learning, shared tooling, and matchmaking with European GenAI start-ups.

#### 1.2 Contribution to Long-Term Policy Objectives

The project contributes to:
- **European AI Strategy** -- Deploying trustworthy AI in the public sector
- **Digital Decade 2030** -- 100% of key public services available online, 75% of EU enterprises using AI
- **Interoperable Europe Act** -- Cross-border interoperability of public services
- **AI Act** -- Demonstrating compliant GenAI deployment in public administration
- **GenAI4EU initiative** -- Building the European GenAI ecosystem of excellence

#### 1.3 Reinforcing the European Digital Supply Chain

Brubru uses a European-first AI provider strategy: **Mistral** (French, primary) with Claude, GPT-4, and Gemini as fallbacks. The platform's multi-provider architecture demonstrates how public administrations can prioritise European AI suppliers while maintaining resilience. This model will be documented as a replicable pattern for other administrations.

### Section 2: IMPLEMENTATION (Evaluation Weight: 5 points)

#### 2.1 Project Maturity

Brubru is not a concept -- it is a **production platform** with:
- 7 integrated modules (Chat, Bubble, Amendator, EU Law Comply, Calendar, Predictions, Document Generator)
- 15+ EU institutional data sources integrated (EUR-Lex, OEIL, EP, Council, Commission, ECB)
- 23 EU languages supported
- 13 test users across Professional and Starter tiers
- Multi-provider AI with 4-tier fallback (Mistral > Claude > GPT-4 > Gemini)
- Stripe payment integration with 9 subscription plans

The CSA will build on this operational foundation to develop scalability/replication tools and community infrastructure.

### Section 4: ETHICS AND COMPLIANCE

#### 4.1 AI Act Compliance
Brubru is designed with AI Act compliance by design:
- Transparent AI provider attribution (users see which model responds)
- Human-in-the-loop for all AI outputs (suggestions, not automated decisions)
- Multi-provider fallback prevents vendor lock-in
- Data processed within EU jurisdictions

#### 4.2 Data Protection
- GDPR-compliant by design
- No personal data required for core legislative analysis functions
- User data stored in EU-hosted PostgreSQL (Supabase, migrating to Google Cloud SQL Europe)

#### 4.3 Accessibility
- WCAG 2.1 Level AA compliance
- 23 EU languages supported via i18n framework
- 6 human-reviewed localisations (EN, ES, CA, FR, IT, NL)
